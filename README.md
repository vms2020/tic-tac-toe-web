# Tic-Tac-Toe Web — Vite Vanilla

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite, usually http://localhost:5173.

## Build
```bash
npm run build
npm run preview
```

This is a front-end prototype. Authentication, game creation, moves, chat and admin tools are local demo interactions only. Firebase is not connected yet. Demo admin shortcut: Ctrl+Shift+A. Do not use real credentials or private messages until Firebase Authentication, Realtime Database and secure authorization rules are implemented and tested.
